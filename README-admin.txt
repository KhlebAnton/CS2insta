# CS2 Insta Smokes — Admin

## Как установить

Положи эти файлы рядом с существующим проектом:

admin.html
admin.css
admin.js

Открой `admin.html`.

## Как работать

1. Нажми `Импорт data.js` и выбери текущий `js/data.js`.
2. Выбери карту или создай новую.
3. Выбери сторону/место или создай своё.
4. Нажми по изображению карты — создастся точка.
5. Заполни название, бросок, цель, позицию и описание.
6. Выбери Aim и Result картинки.
7. Нажми `Сохранить`.
8. Нажми `Скачать data.js`.
9. Замени старый `js/data.js` новым.

Загруженные через форму изображения сохраняются прямо внутри `data.js` как Data URL. Поэтому отдельное копирование этих картинок в папки проекта не требуется.

ВАЖНО:
Текущий сайт должен использовать динамические стороны из `smokeData`, если ты хочешь создавать не только T/CT, но и произвольные места вроде `A Site`, `B Site`, `Mid`, `Long` и т.д.
